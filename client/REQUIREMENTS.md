## 기능 요구 사항

- [] API 호출
  - [] 특정 프로덕트를 가져온다.
  - [] 장바구니내 아이템 리스트를 가져온다.
  - [] 장바구니내 아이템 수량을 수정한다.
  - [] 장바구니내 아이템을 제거한다.

- [] 상태
  - [] 상품
  - [] 선택된 상품(상품 id)
  - [] 결제 금액(파생 -> 선택된 상품)
  - [] 배송비(파생 -> 선택된 상품)

- [] API 상태
  - [] idle | loading | success | error
  - [] 에러시 사용자에게 보여준다
  - [] 스켈레톤 UI

- [] 로컬스토리지
  - [] 선택된 상품을 로컬스토리지에 저장한다.

- [] 새로고침
  - [] 새로고침 시에도 선택된 상품은 유지되어야 한다. (useEffect of useSyncExternalStore, 부모/자식 컴포넌트 렌더링, 초기값 localStorage로부터)

- [] 라이브러리
  - [x] Storybook
  - [] MSW
  - [] RTL
  - [] Jest
  - [x] React-Router
  - [x] Emotion
